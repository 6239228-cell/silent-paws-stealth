Silent Paws 夜爪潜行 — a top-down stealth game: guide a cat through a moonlit mansion, dodge the butlers' vision cones, hide in the bushes, toss coins to distract them, and slip out the open window.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve game/ with any static server.
